# Гастрокод — флипбук (май 2026)

Онлайн-версия журнала «Гастрокод», 110 страниц.

## Что где
- `pages/` — страницы журнала (`page-001.webp` … `page-110.webp`) + `manifest.json`. Раздаются через CDN jsDelivr.
- `index.html` — тонкий флипбук (~12 КБ): люкс-лоадер, переворот страниц, оконная подгрузка по сети. Картинки тянет с jsDelivr.
- `build/` — скрипты рендера из PDF.
- `og-cover.jpg` — карточка-превью для соцсетей (1200×630), используется og-тегами.
- `_source/` — исходники (PDF, одностраничная сборка, превью). Не публикуется (в .gitignore).

## Как работает
`index.html` грузит страницы по адресу
`https://cdn.jsdelivr.net/gh/amarshalkin/kuzmenko@main/pages/page-XXX.webp`
по мере листания (текущая ± соседние). Лоадер отражает реальную сетевую загрузку.

## Управление
ПК — колесо/стрелки. Мобайл — свайп или тап по краю. Кнопка «Скачать» ведёт на PDF.

## Обновить журнал
Заменить файлы в `pages/`, закоммитить, запушить. jsDelivr подхватит (кэш `@main` обновляется; для мгновенного — указать коммит-хеш в `index.html`).

## Соцсети-превью
`index.html` содержит og/twitter-теги. Работают, если страница отдаётся как обычный сайт (GitHub Pages), а НЕ внутри iframe p.knotta. Для богатого превью делитесь ссылкой GitHub Pages: https://amarshalkin.github.io/kuzmenko/
